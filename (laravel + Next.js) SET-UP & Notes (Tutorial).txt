Next.js is for the Frontend
Laravel is for the Backend


-create a folder "project_name" and inside that folder will contain the frontend(Next.js) and back end(Laravel)

-inside the project_name folder create/install a Frontend(Next.js) in the cmd of the "project_name"
-use these code
npx create-next-app@latest
name: frontend
typescript: yes
-in vscode terminal of the next.js(frontend) run these code
laravel (to install laravel in next.js or to know if it is installed)
npm run dev (this code is used to run the next.js)

-after installing next.js(frontend)
-install laravel named "api-backend" inside the project_name folder
-use these code to install in cmd of the project_name
laravel new api-backend
starter kit: none
wait...
databse: mysql
default migrations: yes (make sure the XAMMP is running)
npm: yes / no (depends but I selected yes)
-now it's finished
-cmd the api-backend folder and run code .(vscode)
-make sure the laravel is connected to the database
-if migration is failed use this code to migrate
php artisan migrate
-create a model use this code
php artisan make:model Product -m (it will create a model and migration)
-in the product_migration put the required columns for the product table(id,....foreignId)
-migrate again and check the XAMPP Database
-in models/product.php insert this code
protected $fillable{'id','?','?'}
-after the model and migration are done run this code for the api
php artisan install:api (it will also create a api.php route)
pending migration: yes
-check the database if the tokens table are created
-check the terminal info or instructions
-after successfully istalled api & tokens make sure to add this "use Laravel\Sanctum\HasApiTokens"
-in the class User extend Auth... add HasApiTokens next to Notifiable
-make an AuthController
php aritsan make:controller AuthController
-after i make the controller I create the register, login, profile, logout APIs
-then i created the routes for (register, login, &etc.) in api.php
-then i created the Controllers for (register, login,  etc.) in AuthController.php 
-then i created the ProductController using this code
php artisan make: ProductController --resource --api
-then i create the controllers of ProductController
-then i create the api routes for product contollers


-then on the frontend , I installed these packages
-bootstrap

npm install bootstrap axios react-hot-toast sweetalert2 js-cookie
